Teste de Programa para Aulão Solidário na UFV

## Como rodar

1. Baixe e instale o Node.js.
2. Abra o terminal na pasta `aulao-solidario`.
3. Rode o comando:

```bash
npm install
```

4. Depois, inicie o projeto com:

```bash
npm run dev
```

5. Abra no navegador o link gerado no terminal, normalmente algo como:

```text
http://localhost:5173
```

## Instruções de uso

1. Acesse a página inicial pelo navegador.
2. Navegue pelas telas disponíveis para visualizar as informações do Aulão Solidário e faça login na página de administrador (a senha estará lá).
3. Caso exista formulário de inscrição, preencha os campos solicitados com atenção.
4. Revise as informações antes de enviar qualquer cadastro ou resposta.
5. Se fizer alterações no código, salve os arquivos e aguarde o navegador atualizar automaticamente.

## Comandos úteis

```bash
npm run dev
```

Inicia o projeto em modo de desenvolvimento.

```bash
npm run build
```

Gera a versão final do projeto para produção.

```bash
npm run preview
```

Abre uma prévia local da versão gerada para produção.
